Crop yield estimation of × Triticosecale Wittmack\
using UAV spectral and manure treatment data\
deriving predictors from vegetation index pixel and time series statistics\
comparing multiple models\
performing predictor selection by Elastic Net method and Genetic Algorithm\
comparison of different predictor combinations.


Location: Nyíregyháza, Hungary\
Growing seasons: 2023/2024 and 2024/2025\
Number of parcels: 20 in both periods
